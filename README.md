# Data-201-Project1

## Project Description
This project aims to classify predicted probabilities of subscribing to a bank product through evaluating four classification models : KNN,QDA,LDA, and Logistical Regression.
One model will be chosen at the end as the final prediction and classification model.
## Main Findings

Logistical Regression at a .2 threshold had the highest ROC-AUC(.7734), F1(Tied with LDA), and mean CV F1 score. This model and threshold value was the final model chosen to predict and classify probabilities of subscribing to a bank product into two binary classes (Subscribed or not Subscribed).
